## 下载大文件

原始 ZIP 和 CS5298 录音使用 Git LFS 保存。通过 Git 克隆时，请先安装 Git LFS，然后运行：

```bash
git lfs install
git clone <本仓库地址>
```

如果已经克隆但 ZIP 或 MP3 只有几行文本，请在仓库目录运行 `git lfs pull`，下载完整文件。
